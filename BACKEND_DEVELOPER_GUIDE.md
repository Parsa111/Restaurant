## 📜 2. Supabase SQL Table Definition

Run this SQL query in your **Supabase Dashboard -> SQL Editor** to create the `reservations` table and security policies:

```sql
-- 1. Create the 'reservations' table
create table public.reservations (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  booking_code text not null,
  guest_name text not null,
  guest_email text not null,
  guest_phone text not null,
  res_date text not null,
  res_time text not null,
  res_guests integer default 2,
  res_seating text default 'Main Dining Room',
  res_notes text,
  status text default 'Confirmed'
);

-- 2. Enable Row Level Security (RLS)
alter table public.reservations enable row level security;

-- 3. Security policies to allow public reservation bookings and live admin reads/deletes
create policy "Allow public to insert reservations" 
  on public.reservations for insert with check (true);

create policy "Allow public to read reservations" 
  on public.reservations for select using (true);

create policy "Allow public to delete reservations" 
  on public.reservations for delete using (true);
```

## 👑 3. Live Admin Dashboard & 2-Way Deletion Sync

The Admin Dashboard is available at **[`admin.html`](file:///c:/Users/DELL/Desktop/wordpress/admin.html)** / **[https://wwwee.vercel.app/admin.html](https://wwwee.vercel.app/admin.html)**:

- **Live Database Fetch**: Automatically queries Supabase REST API (`GET /rest/v1/reservations?select=*&order=created_at.desc`) on load.
- **2-Way Deletion Sync**:
  - Deleting a row in your Supabase Dashboard immediately removes it from the Admin page upon refresh.
  - Clicking the red **`🗑️ Delete`** button next to any reservation on `admin.html` sends a `DELETE /rest/v1/reservations?id=eq.{id}` request to Supabase to remove it live from the database.
- **1-Click Export**: Download all reservations to a `.csv` file for Microsoft Excel.
