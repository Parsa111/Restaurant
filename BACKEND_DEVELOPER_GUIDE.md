## 📜 2. Supabase SQL Database Schema

Execute the following script in the **[Supabase SQL Editor](https://supabase.com/dashboard/project/praocrdvlavznipehkek/sql)** to create the `reservations` table and configure Row Level Security (RLS) policies:

```sql
-- 1. Create the 'reservations' table
CREATE TABLE IF NOT EXISTS public.reservations (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
  booking_code TEXT NOT NULL,
  guest_name TEXT NOT NULL,
  guest_email TEXT NOT NULL,
  guest_phone TEXT NOT NULL,
  res_date TEXT NOT NULL,
  res_time TEXT NOT NULL,
  res_guests INTEGER DEFAULT 2,
  res_seating TEXT DEFAULT 'Main Dining Room',
  res_notes TEXT,
  status TEXT DEFAULT 'Confirmed'
);

-- 2. Enable Row Level Security (RLS)
ALTER TABLE public.reservations ENABLE ROW LEVEL SECURITY;

-- 3. Security policies to allow public reservation bookings, reads, and deletes
CREATE POLICY "Allow public to insert reservations" 
  ON public.reservations FOR INSERT WITH CHECK (true);

CREATE POLICY "Allow public to read reservations" 
  ON public.reservations FOR SELECT USING (true);

CREATE POLICY "Allow public to delete reservations" 
  ON public.reservations FOR DELETE USING (true);
```

> [!IMPORTANT]
> If Row Level Security (RLS) is enabled without the above policies, client-side fetches (`GET`) and insertions (`POST`) will return HTTP 401/403 errors.

## 👑 3. Admin Dashboard & 2-Way Deletion Sync

The Admin Dashboard is located at [`admin.html`](./admin.html) / [https://wwwee.vercel.app/admin.html](https://wwwee.vercel.app/admin.html).

### Features & Workflows:

1. **Real-time Data Fetching**:
   - Queries `GET https://praocrdvlavznipehkek.supabase.co/rest/v1/reservations?select=*&order=created_at.desc`.
2. **2-Way Synchronized Deletion**:
   - **Database to Admin**: If a row is deleted directly inside the Supabase Dashboard, refreshing `admin.html` instantly reflects the deletion.
   - **Admin to Database**: Clicking **`🗑️ Delete`** sends `DELETE https://praocrdvlavznipehkek.supabase.co/rest/v1/reservations?id=eq.{ID}`, removing the entry live from PostgreSQL and removing the table row immediately from view.
3. **1-Click CSV Export**:
   - Downloads all active reservations into a `.csv` file formatted for Excel or Google Sheets.
